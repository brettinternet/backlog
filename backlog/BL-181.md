Read the parent epic's Writes section first. It is the settled design, including what stays out of scope (merging, branch updates, re-runs, closing). This child lets a reviewer or author act on a pull request without the browser.

## Scope

| Action | Key | Mutation |
| --- | --- | --- |
| Resolve or unresolve the thread under the cursor (Conversation or Diff) | `x` | `resolveReviewThread`, `unresolveReviewThread` |
| Toggle viewed on the file under the cursor (Files or Diff) | `v` | `markFileAsViewed`, `unmarkFileAsViewed` |
| Request review | Palette `Request review…` | `requestReviews` with `union: true` |
| Re-request the reviewer under the cursor | Palette `Re-request review` | `requestReviews` with `union: true` |
| Ready for review or convert to draft | Palette | `markPullRequestReadyForReview`, `convertPullRequestToDraft` |

- The request-review picker lists suggested reviewers (`suggestedReviewers`), previous reviewers, and code-owner teams, and accepts a typed login or `org/team`. It resolves logins to node IDs on the worker.
- Each write is one mutation on the worker through the account queue and is never retried. The entry shows a pending mark until a re-read confirms the result. After an unknown outcome, the re-read decides what shows; these writes are idempotent, so this is safe. A refusal stays visible with the forge's reason (D15).
- Gate with D10 exactly like `c` and `r`. Without a write-capable account, or without Pull requests: write on `bl-cli`, each action is disabled with the reason. GitLab forges don't implement these writes.
- Extend D45 with the writes and keep the D43 non-goal. Add the shipped action examples `gh pr merge {change.number}` and `gh pr update-branch {change.number}` to docs/automation.md.

## Tests

- Fake-server tests in `internal/source/github`: each mutation's input, no retry after dispatch, and an unknown outcome reconciled by the re-read. These catch a double toggle that would undo the user's action.
- D10 gating reasons, extending `TestOAuthInstallationPermissionGatedWrites`.
- TUI routing of `x` and `v` by tab and entry.
