The MCP tour tool takes only a file path, which fails when the agent doesn't share bl's filesystem (a sandbox, a container, another machine). Accept the tour itself: an MCP argument holding the tour object, and bl tour ID - reading stdin. Both go through the same validator and limits as a file.

## Acceptance criteria

- [ ] The MCP tour tool accepts a tour argument with the tour object instead of file; giving both or neither is refused with the reason
- [ ] bl tour ID - reads the tour from stdin
- [ ] Inline tours pass the same validator, size limit, and refusals as files; a parity test covers CLI stdin and MCP inline
- [ ] docs/mcp.md, docs/cli.md, and bl instructions tours show the inline form

## Definition of done

- [ ] task ci passes on the final commit
- [ ] Every checked acceptance criterion has --evidence naming the verification command and its result
- [ ] Substantial changes had an independent verifier pass that returned PASS for every acceptance criterion

- [ ] No test was deleted, skipped, or weakened
