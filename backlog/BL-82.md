Agents can only tick definition-of-done items through `bl edit`, which opens $EDITOR. Add `--dod` to `bl ac` and an optional `list` argument (criteria|dod) to the MCP `criteria` tool. The format and adapters already accept the DoD section; only the CLI and MCP entry points hardcode acceptance criteria.

## Acceptance criteria

- [ ] `bl ac ID check|uncheck|add|rm ... --dod` changes DoD items with the same rules and evidence as criteria
- [ ] MCP `criteria` accepts `list: dod`; omitted defaults to criteria
- [ ] cli.md, mcp.md, design.md, bl instructions, and AGENTS.md document DoD checks

## Definition of done

- [ ] task ci passes on the final commit
- [ ] Every checked acceptance criterion has --evidence naming the verification command and its result
- [ ] Substantial changes had an independent verifier pass that returned PASS for every acceptance criterion
- [ ] The diff stays within the task's modified-file list, or Implementation Notes justify the deviation
- [ ] No test was deleted, skipped, or weakened
- [ ] User-visible behavior changes are reflected in README.md or docs/ in the same change
