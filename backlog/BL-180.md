Read the parent epic's Conversation, Diff, and Files layouts first. They are the settled design. This child makes review feedback navigable: every thread is visible where it applies, and files, threads, and Diff lines link to each other.

## Scope

- **Read.** Add the first comment's `diffHunk` to thread reads.
- **Inline threads.** The Diff renders each thread under its line, on its side in split. Unresolved threads are expanded; resolved threads fold to one line, and `enter`/`za` toggles them. Drafted line comments render the same way, marked `draft`. Outdated threads aren't placed on head lines; they stay in Conversation. Thread rows aren't line anchors, so line comments and tours keep their addressing (BL-157). Rendering is cached with the file (head, file, width, theme, plus a thread-set hash).
- **Jumps.** `]u`/`[u` move to the next or previous unresolved thread across files, wrapping, and say so when there are none. `enter` on a Files entry opens the Diff at that file. `enter` on a Conversation thread opens the Diff at its line. BL-176's "unresolved threads" Merge reason retargets to the Diff's first unresolved thread. `backspace` returns to the entry you came from.
- **Conversation.** Order: unresolved threads by file and line, then reviews and comments oldest first, then one folded entry for resolved threads. A thread shows the last four lines of its hunk. Bodies render as Markdown with the description's renderer, on the worker, cached, falling back to plain text as today.
- **Counts.** Each Files row shows its unresolved thread count. The Conversation tab count shows unresolved threads.
- **Agents.** `--detail` and MCP `detail` add `threads` (`id`, `path`, `line`, `resolved`, `outdated`, `hunk`, `comments` with `author`, `body`, `time`, `url`).

## Tests

- Thread placement on the right file, side, and line, including renamed files and the unified/split switch. It catches a thread drawn on the wrong line after a layout change.
- `]u` wraps and skips resolved and outdated threads.
- Held `j` budget with inline threads (`BL_TUI_MEASURE=1`).
