bl new, TUI create and MCP create apply defaults.type and defaults.dod to every template (internal/cli/write.go, internal/mcp/server.go create, TUI create). Linear create rejects a non-issue type and any DoD (engine linearCreate, BL-112), so in a project that sets those defaults every Linear create fails, e.g. a project with native tasks using a DoD default plus a Linear source. Apply the defaults only to sources that can store them (native, Backlog.md) and keep the explicit rejection for user-supplied values. Update docs/linear.md (Create row mentions the defaults) and docs/cli.md in the same commit.
