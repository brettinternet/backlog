A `bl auth login --write` replaces the account token with the bl-cli token, so the linked-changes forge then reads pull requests with bl-cli. Its Issues and organization Projects grant lacks Pull requests, Checks, and Commit statuses: read, so the forge should report unavailable for write-enabled device-login accounts. Untested; found while verifying BL-147. Changing App permissions is an owner step, and each installation must approve it.
