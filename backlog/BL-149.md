Phase 4 of BL-103: a GitLab forge for merge requests through the same internal/changes forge interface as GitHub. bl has no GitLab source, so this adds a GitLab account (gitlab.com or a self-managed host, with a read_api token from `credential` or `env`, as Linear's API key) that only the forge uses. See BL-103 and docs/changes.md.

## Acceptance criteria

- [x] A `type: gitlab` forge with a GitLab account fetches merge requests through the account's request queue into a per-project cache with an updated cursor, and a failed refresh keeps the cached merge requests marked stale
  Evidence: go test ./internal/source/gitlab (TestForge): GraphQL list through remote.Client queue, cursor sent as updatedAfter 2026-01-03T00:00:00Z, 502 refresh returns 4 cached MRs with error (LoadForges marks stale); commit 00e21f3

- [x] A merge request links by source branch, whole-word ID in the title, or a closing pattern in the description, and shows state (draft, open, merged, or closed), pipeline status as checks, approval as review, and +/−
  Evidence: TestForge: draft/open/merged/squash states, pipeline RUNNING→pending, FAILED→failing, SUCCESS→passing, approvals/reviewer states→review, diffStatsSummary +3/−1; linking via generic changes.Link (TestLinkStates, !7 label); verifier PASS

- [x] A GitLab `origin` with exactly one GitLab account for its host is the forge without configuration, as for GitHub
  Evidence: go test ./internal/engine -run TestOriginForge: one GitLab account for origin host → gitlab grp/sub/app forge; ambiguous accounts → none; never borrows a GitHub account

- [x] change:, checks:, and review: match linked merge requests, and bl changes --json and MCP changes report them with the GitLab forge in providers
  Evidence: Verifier code trace: query/eval.go change:/checks:/review: and engine ItemChanges/linkReads are provider-generic; providers carry Name() 'gitlab group/proj'; TestLinkStates links a GitLab MR through Link

- [x] The token never reaches the cache, events, or logs, and tests use a fake server unless BL_PROVIDER_TESTS=1
  Evidence: TestForge asserts fake-secret absent from cache file, MR body, Pull detail, and Review; forge emits no events or logs; live test gated by BL_PROVIDER_TESTS=1

- [x] docs/changes.md, a GitLab setup page, and the D43 row describe the GitLab forge, its account, and its token scope
  Evidence: docs/gitlab.md (setup, read_api scope, mapping), docs/changes.md forge table/auto-detect, design.md D43 row, README link; commit 00e21f3
