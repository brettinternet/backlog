Phase 3b of BL-103: the Diff tab in the change view (BL-156). Local stages diff with git on a worker, landed changes diff the merge against its first parent, and pull requests without a local head use the forge's per-file patches. BL-150's line comments and BL-151's tours anchor to diff lines, so address each by file, side, and line at a head SHA. See BL-103's change view design.

## Acceptance criteria

- [x] The Diff tab shows the change's diff unified below 120 columns and split at 120 or wider, highlighted with chroma, with word-level intra-line changes
  Evidence: go test ./internal/tui -run TestChangeDiff: unified at width 100 (no │, line-number gutter), split at detail content ≥120 (│); verifier probe confirmed chroma token colors and stronger word-change backgrounds (0197285)

- [x] `[`/`]` jump files, `[c`/`]c` jump hunks, and `/` searches the diff, as in detail
  Evidence: TestChangeDiff steps ] ] [ [c [c ]c and asserts scroll equals detailFiles/detailHunks; / uses openFind over detailLines in Diff (verifier read model.go). PASS

- [x] A branch or worktree diffs against its merge base with the default branch plus a worktree's uncommitted changes, a landed change diffs its merge against the first parent, and a pull request without a local head uses the forge's per-file patches, saying when the forge truncated a file
  Evidence: TestWorktreeToLanded asserts worktree patches vs merge base incl. untracked, landed sha^1..sha, CommitChange incl. root commit; TestForgePullRequests asserts forge Patch and 'GitHub left out this file's diff'. PASS

- [x] Git runs on a worker with --no-ext-diff --no-textconv, no pager, and D21's environment, and skips uncommitted changes when repository config defines a filter driver; a test asserts configured external diff, textconv, and filter commands never run
  Evidence: TestWorktreeToLanded sets diff.external, textconv, filter.x.clean to a marker script; marker never created; filter config yields skip Reason; removing --no-ext-diff --no-textconv fails the test. git.Run passes --no-pager and minimal env. PASS

- [x] Rendering is async and cached by head SHA, file, width, and theme; files over 32 KiB render on `m` up to 128 KiB, and held `j` over a 10,000-line diff meets the §11 budget
  Evidence: diffPage runs in detailWorker.prepare; per-file LRU keyed head/path+patch hash/width/theme/expanded; TestChangeDiff: 'KiB diff' then m draws line 1499; BL_TUI_MEASURE=1 held j in 10,299-line diff p95=89µs max=444µs (budget 4 ms). PASS

- [x] `enter` on a History commit row opens that commit in the Diff tab
  Evidence: TestChangeDiff: enter on git:abc1234 History entry opens commit:abc1234 on Diff tab (≥10,000 lines); backspace returns to that History entry. PASS
