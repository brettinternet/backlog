CLI agents can only replace plan, summary, description, or notes through `bl edit --section`, which opens $EDITOR, yet AGENTS.md directs them there. Rewording a criterion or DoD item takes rm then add, which reorders it and drops its evidence. Add `bl edit ID --section S --text TEXT|-` (stdin for -) and `bl ac ID set N TEXT [--dod]`, with a `set-criterion` model operation, MCP `criteria` operation `set`, and adapter support in native and Backlog.md.

## Acceptance criteria

- [ ] `bl edit ID --section S --text TEXT|-` replaces one section without launching $EDITOR and honors --if-version
- [ ] `bl ac ID set N TEXT [--dod]` rewords one entry in place, keeping its check state, position, and evidence, on native and Backlog.md sources
- [ ] MCP `criteria` accepts operation `set`; external adapters may advertise `set-criterion`
- [ ] cli.md, mcp.md, design.md, format.md, external-adapter-protocol.md, bl instructions, and AGENTS.md document both

## Definition of done

- [ ] task ci passes on the final commit
- [ ] Every checked acceptance criterion has --evidence naming the verification command and its result
- [ ] Substantial changes had an independent verifier pass that returned PASS for every acceptance criterion
- [ ] The diff stays within the task's modified-file list, or Implementation Notes justify the deviation
- [ ] No test was deleted, skipped, or weakened
- [ ] User-visible behavior changes are reflected in README.md or docs/ in the same change
