### Why

`bl` claims run through the `worklease` binary. Worklease's go-rewrite contract D3 rules out Windows, and `GOOS=windows go build ./...` fails in `internal/handle` (`unix.Stat_t`, `Fstat`, `Fstatat`). `internal/guard`, `internal/runs/detach.go`, `internal/store/hosted.go`, and `internal/cli/guided_setup.go` are also Unix-specific.

This work happens in the Worklease repository, so it needs the owner.

### Shape

Amend Worklease D3 to add `windows/amd64` and `windows/arm64`. Port the owner-private path and handle checks to Windows ACLs and file IDs, port locks to `LockFileEx`, and port detached runs to Windows process creation flags. Add Windows CI and release archives.

## Acceptance criteria

- [ ] The Worklease go-rewrite contract D3 lists windows/amd64 and windows/arm64
- [ ] Worklease builds and passes its tests on Windows CI, with owner-private path checks, locks, and detached runs ported to Windows
- [ ] A tagged Worklease release publishes Windows archives
