`bl new` requires `--source` whenever a project has more than one source, and TUI `n` always asks. Adding any remote source, even one that can't create, breaks agent `bl new` calls that omit `--source`.

Resolve the create target in one shared function used by the CLI, TUI, and MCP `create`, first match wins:

1. Explicit: `--source ID` (MCP `source`) or a `+ID` quick-add token. Both given and different is a usage error.
2. `defaults.source` from config (shared, local, or user `projects.<id>`).
3. The only source whose capabilities allow Create.
4. Otherwise a usage error listing the creatable sources.

An unknown or non-creatable source is a usage error that names the creatable ones. `+` is unused by the quick-add parser (`internal/query/quickadd.go`); `\+` keeps it as title text. TUI `n` preselects the resolved source instead of prompting, and `N` keeps creating in the parent's source. `bl config show` reports `defaults.source` and where it came from.

Update docs/query.md (quick-add), docs/tui.md, docs/cli.md (`bl new`), docs/mcp.md, docs/guide.md config, and the design.md register.
