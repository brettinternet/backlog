enter on a Commits tab entry opens that commit's Diff in the change view, as History already does (openCommit), and backspace returns to the parent change's Commits tab with the cursor on that commit. This nests one change view level under another. A single commit's Diff starts with its author, age, and full message (subject and body wrapped to the pane, like git show) above the first file; branch and pull request Diffs are unchanged. Commit gains Body, read with %b for the one commit on the Diff worker, or from the forge for a pull request without a local head. The Commits list stays one line per commit. See the BL-150 conversation: inline expansion was rejected because it would duplicate the Diff tab.
