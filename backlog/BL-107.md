### Why

Once `bl` runs on Windows, users need published binaries and a way to install them. `install.sh` is POSIX sh and only fetches `.tar.gz` archives.

### Shape

`scripts/release` also builds `bl_windows_amd64.zip` and `bl_windows_arm64.zip` (static, `CGO_ENABLED=0`, same version metadata), and lists them in `checksums.txt`. A PowerShell `install.ps1` downloads and verifies an archive the same way `install.sh` does: exactly one checksum entry, a valid SHA-256, and nothing installed on a mismatch. It installs into a per-user directory and prints how to add that directory to `PATH`.
