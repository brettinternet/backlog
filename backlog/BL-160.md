bl tour, MCP tour, and the {"tour": PATH} result accept a step on a file or line the change lacks; the reviewer then sees "line N isn't in this diff" and the agent never learns. Storing resolves every step against the file at ref (or its parent for side old, and a renamed file's old path), off the TUI, with changes.FileAt, and refuses with every bad step listed so an agent can fix them all in one pass. Builds on BL-151.

## Acceptance criteria

- [x] Storing a tour refuses a step whose file doesn't exist at ref (or before the change for side old) or whose line is past the file's end, naming each bad step's index, file, line, and the file's line count
  Evidence: go test ./internal/engine -run TestCheckTourSteps passes: steps 6-9 refused with index, file, line, and line count ('no such file at <ref>', 'past the end of the file, which has 3 lines at <ref>', '... 5 lines before the change'); bin/bl tour BL-160 on a bad tour printed the same at commit de815c3.
- [x] All bad steps are reported in one refusal, in the human and --json outputs and the MCP error
  Evidence: One source.Refuse lists every bad step joined by '; ': bin/bl tour BL-160 bad.tour printed steps 1, 2, 4 in human output (exit 5) and error.message of --json; MCP tour returns the same engine error via StoreTourFile.
- [x] Steps on files the change doesn't touch but that exist at ref are accepted, since the Diff shows them with context
  Evidence: TestCheckTourSteps accepts keep.go (untouched by the change) and old/new rename paths; live run accepted README.md step 3 (not in the change).
- [x] The check reads git objects at ref only, never the worktree, and stays within D14 (no work on the update loop)
  Evidence: changes.Sides reads only cat-file/merge-base/diff of commits; TestCheckTourSteps refuses keep.go line 9 though the worktree file has 10 lines. Runs in engine.StoreTour (CLI, MCP, hook runner), never the TUI update loop.
- [x] bl instructions tours and docs/cli.md describe the check
  Evidence: internal/instructions/tours.md and docs/cli.md describe the check; design.md D43 updated.
