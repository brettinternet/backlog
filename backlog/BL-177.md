Read the parent epic's "List and navigation" section first. It is the settled design. This child makes pull requests reachable and scannable from the list, whether a task links them or they are `github-pulls` items (D44).

## Scope

- **List read.** Add `mergeStateStatus`, `reviewRequests(first:10)`, and `latestReviews(first:10){author{login} state}` to `pullsQuery` (`internal/source/github/pulls.go`). Store them redacted in `.pulls.json`, and measure the added query cost in Notes. GitLab leaves them empty.
- **List glyph.** The `changes` cell's last glyph becomes BL-176's `Verdict` glyph, using the epic's precedence. Drafts and an unknown merge state keep the checks glyph. The cell width is unchanged. The help overlay legend and `docs/tui.md` list the glyphs.
- **Queries.** `merge:ready|unstable|blocked|behind|conflicts` and `reviewer:me|LOGIN|org/team` are evaluated from the list read in the projection worker, like `checks:`. `me` is the login of the forge's account. Like other change terms, they are refused in hooks. Malformed values are usage errors (query.md). Document the two example views.
- **`gp`.** From the list or detail: open the item's furthest open pull request in the change view, or its Changes tab when it has several. When it has none, the action is disabled with the reason.
- **PR items.** Detail on a `github-pulls` item opens in its own pull request's change view. `backspace` shows its item tabs.
- **`J`/`K`.** With a change view open, the next or previous item opens on its furthest pull request in the same tab. An item without one shows its item tabs.
- **Go-to.** `ctrl-p` with `#45`, `!12`, or a pull request URL selects the item showing that pull request (its linking item or PR item), else it says that no item shows it.

## Tests

- `merge:` and `reviewer:` semantics in `internal/query` or `internal/engine`, wherever `checks:` is tested. They catch `me` resolving to the wrong account and a team slug failing to match.
- TUI key routing for `gp`, PR item auto-open with `backspace`, and `J` keeping the tab, extending `TestChangeView`.
- Fuzz: extend the query fuzz corpus with the new terms.

- [ ] merge: and reviewer: filter from the list read, are refused in hooks, and reject malformed values as usage errors; docs/query.md documents them with example views

- [ ] A github-pulls item opens into its change view and backspace shows its item tabs; J and K keep the change view tab; ctrl-p with #N, !N, or a pull request URL selects the item that shows it
