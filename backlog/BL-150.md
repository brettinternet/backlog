Phase 5 of BL-103: pull request comments, line comments on BL-148's Diff, replies to threads in BL-154's Conversation, and approve or request changes. A pending review is drafted in XDG state and submitted in one non-retried call, with D15 conflict and unknown-outcome rules, capability-gated per forge (D10). Needs Pull requests: write on bl-cli (BL-155, owner step). See BL-103.

## Acceptance criteria

- [ ] From the change view, a pull request comment, a comment on the Diff line under the cursor, and a reply to a Conversation thread can be drafted, and drafts persist in XDG state per change across restarts

- [ ] Submitting sends the pending review as comment, approve, or request changes in one non-retried call, and an unknown outcome is reported and never resent

- [ ] A draft whose pull request head moved shows stale and never posts onto other lines, and a write conflict stays visible (D15)

- [ ] Without a write-capable account the review actions are disabled with the reason (D10)

- [ ] docs/github.md names Pull requests: write on bl-cli as an owner step (BL-155)

## Definition of done

- [ ] task ci passes on the final commit
- [ ] Every checked acceptance criterion has --evidence naming the verification command and its result
- [ ] Substantial changes had an independent verifier pass that returned PASS for every acceptance criterion
- [ ] The diff stays within the task's modified-file list, or Implementation Notes justify the deviation
- [ ] No test was deleted, skipped, or weakened
- [ ] User-visible behavior changes are reflected in README.md or docs/ in the same change
