With coordination on, report open items in an active-category status whose claim is missing or expired, so a person can resume, reset, or close abandoned work. bl does not auto-reclaim lapsed items: a task that repeatedly kills its agent would loop and starve the queue.

  Evidence: Built bl and ran `bl doctor` on a temp project with coordination, one in-progress and one todo item, and a fake worklease returning no claims: `warn claims Active without a live claim: BL-1` (todo not listed). On this repo with BL-91 claimed: `pass claims`. Only native/backlog-md sources load; claims come from one ClaimStates list call.
- [x] The check skips without coordination and skips (never fails) when the claim list is unavailable
  Evidence: Without coordination it returns skip. With the fake worklease list exiting 1: `skip claims Claim list unavailable: worklease execution failed: exit status 1`, and doctor exit 0.
- [x] docs/cli.md documents the check
  Evidence: docs/cli.md lists nine checks, adds the claims example line and a `claims` bullet; design.md §9 records that lapsed claims are never reclaimed.
