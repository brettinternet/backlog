Shared prerequisite for BL-150 (comment on the Diff line under the cursor) and BL-151 (tour steps on a file, side, and line). BL-148 shipped the Diff tab with scrolling only and no line identity, so both would otherwise build their own mapping. Build it once here.

## Acceptance criteria

- [ ] The Diff tab has a line cursor, and each diff row resolves to (head SHA, file, side old|new, line); a split row resolves each half, and file and hunk headers resolve to their file
- [ ] Given an anchor (head, file, side, line), the Diff moves the cursor to that line; an anchor at another head reports stale, and a line outside every hunk reports outside so callers can show it with context
- [ ] Held j over a 10,000-line diff with the cursor stays within the §11 budget, and the mapping is built on the detail worker (D14)
- [ ] docs/tui.md describes the Diff cursor

## Definition of done

- [ ] task ci passes on the final commit
- [ ] Every checked acceptance criterion has --evidence naming the verification command and its result
- [ ] Substantial changes had an independent verifier pass that returned PASS for every acceptance criterion
- [ ] The diff stays within the task's modified-file list, or Implementation Notes justify the deviation
- [ ] No test was deleted, skipped, or weakened
- [ ] User-visible behavior changes are reflected in README.md or docs/ in the same change
