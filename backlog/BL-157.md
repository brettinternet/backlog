Shared prerequisite for BL-150 (comment on the Diff line under the cursor) and BL-151 (tour steps on a file, side, and line). BL-148 shipped the Diff tab with scrolling only and no line identity, so both would otherwise build their own mapping. Build it once here.

## Acceptance criteria

- [x] The Diff tab has a line cursor, and each diff row resolves to (head SHA, file, side old|new, line); a split row resolves each half, and file and hunk headers resolve to their file
  Evidence: go test ./internal/tui -run TestChangeDiff passed: Diff is an entry tab with a cursor; cursorAnchors resolves file and hunk headers to {abc, b.go}, a removed row to old 1, an added row to new 1, and a split row to [new 85, old 85]. Verifier probe also confirmed unified context [new, old] and the no-newline marker as file-only.
- [x] Given an anchor (head, file, side, line), the Diff moves the cursor to that line; an anchor at another head reports stale, and a line outside every hunk reports outside so callers can show it with context
  Evidence: TestChangeDiff passed: gotoAnchor returns anchorStale for head def, anchorOutside for a.go new 50 and for z.go, anchorFound for a.go new 85 with the cursor on 'x := 5 + 1' and on screen; the cursor keeps its line through m expand and the split/unified layout change, including on a hunk header.
- [x] Held j over a 10,000-line diff with the cursor stays within the §11 budget, and the mapping is built on the detail worker (D14)
  Evidence: BL_TUI_MEASURE=1 go test ./internal/tui -run TestChangeDiff -v: held j in a 10299-line diff Update+View p95=84.9us max=401.7us (budget 4 ms). Rows are built in diffPage/fileDiff on the detail worker and cached with each file render; the update loop only swaps slices (D14).
- [x] docs/tui.md describes the Diff cursor
  Evidence: docs/tui.md Diff section describes the cursor: j/k, jumps and search move it, line identity per side at head, split halves, headers naming their file, and keeping its line across expand and layout changes.
