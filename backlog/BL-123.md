After `F` (clear filters) there is no way back to a tab's default except restarting. `fc` already clears filters, so `F` is a redundant alias. Make `F` reset the current tab to its definition (`Base`): query (including sort and group directives), layout, columns, and folds. The `•` mark clears. `fc` keeps clearing filters only. No backwards compatibility needed.
