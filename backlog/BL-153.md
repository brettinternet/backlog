When GET /user/installations returns no installations for the authorizing app, bl auth login fails with insufficient-scope, whose message says to enable writes with --write. That misled BL-147 verification: the real cause was that bl-cli-read was not installed for the user. internal/oauth/github.go installations() returns CodeInsufficientScope for an empty list, a non-bl app slug, a non-read bl-cli-read permission, and no active Issues installation alike.
